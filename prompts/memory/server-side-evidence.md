## 已验证经验

Session 有效期、Token 失效、权限控制、事务一致性和缓存行为通常不在接口层暴露。评审必须给出服务端配置或实现证据；无证据只能得出无法判断，不能基于接口返回格式推断结论。

证据还必须关联到当前需求声明：全仓搜到一段 JWT/校验/事务代码，不代表该入口实际使用它。至少要能从相关业务入口、调用链或适用配置建立关联；如果输入证据无法建立关联，就不引用为支持条件，并列出需补充的路径/配置/运行证据。
