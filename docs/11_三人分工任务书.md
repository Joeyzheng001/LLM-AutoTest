# 三人共同的规则

1. **每天 15 分钟站会**：说清「昨天完成什么 / 今天干什么 / 卡在哪」；
2. **合入标准**：CI 全绿（lint + 类型检查 + 单测）+ 1 人 review 通过；`schemas/`、契约、`.rules/` 的改动需要相关人同意；
3. **分支命名**：`feat/<人>/<序号-短名>`，如 `feat/丙/06-fail-plugin`，当天合入；
4. **红线**（`.rules/llm-integrity.md`，违反直接驳回）：Prompt 不许写死在代码里；LLM 输出必须过 Schema 校验；报告/度量里的任何数字不许由 LLM 产生或修改；降级必须显式标注；兜底仓库结果必须单独分列。
