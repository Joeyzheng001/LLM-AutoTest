## 关键结论摘要（供方案设计直接引用）

1. **范围大、时间短、演示导向**：五种协议 + 六环节闭环在一周内以"每个环节都能跑通"为准，不追求各环节成熟度。
2. **Java 多仓 + 无接口文档**是最大的技术挑战点：需要设计"多仓库代码扫描 → 接口逆向解析"的输入通道，这是后续技术选型的第一优先级。
3. **自动化率以流程节点为口径**：需在方案设计阶段先定义节点清单（需求解析、代码扫描、接口还原、用例生成、执行、报告、缺陷提交、复测、回归沉淀），PoC 演示时实测一次。
4. **映射表是上游产物**：Code Review 三种产出中，逐条需求-代码映射表是风险清单与遗漏功能清单的上游产物，实现时可一次生成、三种视图输出。
