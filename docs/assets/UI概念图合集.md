# LLM-AutoTest UI 概念图合集

- **合集日期**：2026-09-15
- **文档性质**：UI Demo 概念图集中展示页（AI 生成示意图，非可运行界面；图中数值均为虚构示意，使用时须替换为实测数据）
- **详细设计**：逐页规格锚点与验收演示叙事脚本见 [../07_UI演示设计.md](../07_UI演示设计.md)
- **视觉体系**：暗色科技风（深蓝底 #0F172A + 靛青/青绿点缀）；状态色语义固定：绿 = 已完成 / 琥珀 = 人工介入 / 蓝 = 运行中 / 灰 = 待运行

## 3. Code Review 三视图

## 4. 测试报告

![测试报告](./04_测试报告.png)

## 5. 缺陷闭环

## 6. 回归沉淀与度量

![回归沉淀与度量](./06_回归沉淀与度量.png)
