本模块以目录形式聚合三个独立的 Maven 子项目，每个子项目均基于 Spring Boot 3.4 + Java 21 构建可运行的 REST 服务：
- `user-service`：主被测仓库，暴露 `/api/v1/users` 的 CRUD 接口及 `/health` 探针，通过 `GlobalExceptionHandler` 统一异常处理；业务逻辑层埋入缺陷变体文件于 `defects/` 目录，按分支语义独立切换。
- `order-center`：G3 第二仓库，提供 `/api/v1/orders` 的 GET/POST 接口，并在 `src/main/proto/order_query.proto` 中声明 gRPC 契约（静态识别未接入时如实降级）。
- `fallback-simple`：极简兜底仓库，仅含 `PingController` 单接口，当真实仓库解析失败时由编排器标记 `is_fallback=true` 单独呈现。
三者无相互依赖，均由上层编排器（orchestrator）通过 `--repos` 配置驱动启动与调用，产物写入 `/tmp/llm-autotest/<job-id>/` 供 G1/G5 证据收集。
