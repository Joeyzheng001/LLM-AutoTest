- 每个子仓库使用独立的 `pom.xml` 继承 `spring-boot-starter-parent` 并声明 `java.version=21`，保持构建配置自包含。
- REST 控制器统一使用 `@RestController` + `@RequestMapping` 前缀（如 `/api/v1/users`、`/api/v1/orders`）组织接口路径。
- 演示服务采用内存数据结构（ConcurrentHashMap / AtomicLong）实现最小可用后端，不引入数据库等外部依赖。
- gRPC 契约以 `src/main/proto/*.proto` 形式与 Java 源码并列存放，但当前不参与编译，仅作为静态识别物料。
- 缺陷变体集中置于各仓库的 `defects/` 目录并以 `*.DEF-###.java` 命名，主干源码保持干净，通过分支切换注入。
