- 每个 job 子目录包含一套固定命名的 JSON 产物文件（state.json、execution.json、defects.json、interfaces.json 等），形成跨任务一致的产物契约。
- 所有 JSON 产物均声明 `schema_version` 与 `job_id` 字段，便于版本演进与溯源。
- 执行结果统一使用 `passed`、`failure_kind`（assertion/environment）、`failure_reason`、`timeout`、`duration_ms` 描述单条用例结果。
- README.md 采用表格形式记录产生时间、复现命令、LLM 模式与环境依赖，并给出 G1–G5 目标达成对照。
- 回归脚本按 `scripts/regression/<type>/test_TC_XXX.py` 命名并与 `regression_index.json` 中的 archived_at 关联，实现回归资产可追溯归档。
