- LLM 桩通过 system prompt 中嵌入的 JSON 键名（`items`/`interfaces`/`mappings`/`cases`）进行路由分发，各节点输出结构键唯一以避免歧义。
- 所有非真实 LLM 产生的语义内容均附带 `stub_note` 或注释标记（如“桩朴素解析产生”“桩轮转配对”），与真实网关产物区分对待。
- Compose 服务间通过命名网络与 `depends_on` + `healthcheck` 建立启动顺序，共享 `artifacts` 卷持久化产物。
- Nginx 对动态 API 路径 `/api/` 使用 `proxy_pass` 转发，静态资源根目录统一为 `/usr/share/nginx/html`，并按发布策略差异化设置 Cache-Control。
