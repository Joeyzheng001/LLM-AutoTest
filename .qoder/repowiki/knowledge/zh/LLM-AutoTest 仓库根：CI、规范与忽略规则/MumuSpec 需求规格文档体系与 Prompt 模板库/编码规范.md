- 所有文档顶部使用 YAML front matter 声明 module/version/status/created 等元数据，便于统一检索与状态管理。
- 编号采用固定前缀格式：REQ-{模块号}-{NNN}、US-{NNN}、AC-{US编号}-{NN}、TC-{模块号}-{NNN}、RULE-{NNN}，跨文档只引用不另起别名。
- 写作遵循 RFC 风格规范词（MUST/SHOULD/MAY/MUST NOT），禁止「可选其一/建议/大概/尽量」等模糊表述。
- 契约真源分离：对外行为以 09-API 为准、存储以 10-数据模型为准，其他文档不得自创字段名或类型。
- Prompt 文件统一采用 `<节点>-<用途>-v<版本>.md` 命名，变更仅通过版本号递增，禁止原地修改语义。
- LLM 输出必须经 `schemas/` 中对应 JSON Schema 校验，失败按节点失败处理，禁止截取可用部分进入下游。
