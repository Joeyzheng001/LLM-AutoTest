- Python 子服务统一使用 uv 管理依赖并锁定 uv.lock，CI 中通过 `uv sync` 安装后执行 ruff check/format 与 mypy 检查
- Java 子服务基于 Maven + Temurin 21，CI 通过 `mvn verify` 完成编译、测试与验证
- Frontend 子服务使用 pnpm 9 与 Node 20，CI 中依次执行 `pnpm install --no-frozen-lockfile`、`pnpm lint`、`pnpm build`
- 所有子服务均遵循 `.rules/` 下对应的代码风格文档，lint 失败即视为 CI 失败
