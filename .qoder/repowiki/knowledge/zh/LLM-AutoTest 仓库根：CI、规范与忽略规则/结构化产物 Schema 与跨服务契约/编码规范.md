- 每个 Schema 文件顶部声明 `schema_version` 且使用 `const` 固定当前版本，语义变更必须升版本而非原地修改。
- ID 命名遵循横切约定：REQ-xxx、CAND-xxx、IF-<协议>-xxx、TC-xxx、DEF-xxx，并在 Schema 中以正则 pattern 约束。
- 时间戳统一使用 UTC ISO-8601 格式（`format: date-time`），协议枚举统一小写 `rest/grpc/graphql/soap/mq`。
- `is_fallback` 字段在仓库、候选、执行结果中全链路透传，用于区分真实仓库与兜底演示仓库。
- 长任务采用异步 job 模式：POST 返回 JobAccepted（含 job_id + queued/running/completed/failed 状态），GET 轮询获取最终产物。
- 错误响应统一使用 Error 组件（code/message/node_id/details），不泄漏堆栈或路径细节。
