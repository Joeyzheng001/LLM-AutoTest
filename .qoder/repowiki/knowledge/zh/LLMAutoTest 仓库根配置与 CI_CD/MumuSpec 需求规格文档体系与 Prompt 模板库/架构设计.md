本模块由三个相互协作的子目录构成：
- `MumuSpec/`：当前项目已落地的 14 篇规格文档（01~14），按编号顺序组织，以 `01-Spec写作总则与文档编号索引.md` 为元入口，定义编号规则（REQ-M1AT-xxx、US-M1AT-xxx、API-xxx、TC-M1AT-xxx）、写作铁律（PRD 不写 SQL、API 不写像素、契约真源在 09/10）以及 R1→R2→R3→R4 四轮螺旋写作流程。
- `docs/spec-templates/blank/`：与 MumuSpec 一一对应的空白模板，供新项目复制使用；`example-投研助手/` 提供完整示例，含 PM/R4 交叉校验清单等配套物。
- `prompts/`：LLM Prompt 的版本化仓库，遵循 `<节点>-<用途>-v<版本>.md` 命名约定，每个 Prompt 文件头部带元信息块（版本号、对应规格编号、主笔人、变更记录、采样参数），并通过 `schemas/` 中的 JSON Schema 对 LLM 输出做强校验。
依赖方向单向：`MumuSpec` 作为事实基线引用 `docs/` 历史产物并冻结冲突；`prompts` 通过 `schemas/` 约束输出结构，不被业务代码直接内联字符串。
