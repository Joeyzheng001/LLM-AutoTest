本模块由两个并列子目录构成：`schemas/` 存放所有结构化产物（需求条目、源码清单、接口候选、用例、执行结果、缺陷、回归索引、度量等）的 JSON Schema 定义，并通过 `contracts/java-parser.openapi.yaml` 维护服务间 OpenAPI 契约；`prompts/` 存放按 `<节点>-<用途>-v<版本>.md` 命名约定的版本化 Prompt，每个文件以 YAML front-matter（version/spec/owner/changelog/sampling）开头，由 orchestrator 的 `prompts_loader.py` 解析元信息并加载正文。两目录通过文档约定形成强耦合：Prompt 中强制要求 LLM 输出必须符合对应 `schemas/<schema>.json`，校验失败即按节点失败处理，禁止截取部分结果，从而保证从 Prompt → LLM 输出 → 下游产物的全链路类型安全。
