- Schema 定义统一包含 `schema_version` 字段，结构变更必须升版本而非原地修改语义。
- Prompt 文件采用 `<节点>-<用途>-v<版本>.md` 命名，并以 `_template.md` 的 YAML front-matter（version/spec/owner/changelog/sampling）作为头部元信息块。
- Prompt 正文首段强制引用对应 `schemas/<schema>.json`，并要求 LLM 输出经 Schema 校验失败时按节点失败处理，禁止截取可用片段。
- 横切字段遵循三人公共语言约定：ID 形如 `REQ-001` / `CAND-001` / `IF-<协议>-001` / `TC-001` / `DEF-001`，时间戳使用 UTC ISO-8601，协议枚举小写（rest/grpc/graphql/soap/mq），错误结构统一为 `{code, message, node_id?, details}`。
