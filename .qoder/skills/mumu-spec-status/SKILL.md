# 版本状态看板

## 职责

展示 Spec 01-14 文档的版本状态、变更提案和健康度概览。

## 执行步骤

1. **扫描文档目录**
   - 读取 `MumuSpec/`（或 `Spec模板/`）目录下所有 01-14 文档
   - 提取元数据表中的版本号和状态

2. **检查变更记录**
   - 读取每个文档顶部的"变更记录"表
   - 识别进行中的变更（状态为 Draft/Review）

3. **生成状态看板**

## 版本状态说明

| 状态 | 含义 | 操作 |
|------|------|------|
| **Draft** | 草稿，正在编辑 | 可继续修改 |
| **Review** | 审查中 | 等待团队审查 |
| **Approved** | 已批准 | 可交付，变更需走 propose 流程 |
| **Deprecated** | 已废弃 | 不再使用 |

## 使用场景

- **项目看板**：了解 Spec 文档整体状态
- **变更追踪**：查看进行中的提案
- **风险评估**：识别未同步的文档
- **团队协作**：了解谁在修改什么
- **交付准备**：确认所有文档是否 Approved

## 与其他 Skill 配合

- 发现不同步 → 运行 `/mumu-spec-sync`
- 检查健康度 → 运行 `/mumu-spec-check`
- 拆分任务 → 运行 `/mumu-spec-tasks`

## 数据源

从以下位置读取信息：
1. `MumuSpec/`（或 `Spec模板/`）目录下各文档的元数据表
2. 每个文档的"变更记录"表
3. 变更提案目录（如使用 OpenSpec）
