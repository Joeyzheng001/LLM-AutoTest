## 一、概述

本文档为存储侧真源。所有结构化产物的字段定义在此冻结，与 09 API 对外字段对齐。

存储方式：文件系统（JSON），按任务 ID 分目录，路径统一由 orchestrator 的 artifacts 模块管理。

## 二、产物目录结构

```
/data/llm-autotest/
└── {pipeline_id}/
    ├── req_parse/
    │   └── requirements.json
```

## 三、核心数据模型

### 3.1 requirements.json

```json
{
  "schema_version": "1.0",
  "items": [
    {
      "id": "REQ-M1AT-001",
      "title": "需求文档多格式解析",
      "description": "支持 Word / Markdown / Excel 三格式",
      "priority": "P0",
      "source_file": "requirements.md"
    }
  ]
}
```

### 3.2 code_inventory.json

```json
{
  "schema_version": "1.0",
  "repositories": [
    {
      "path": "/path/to/repo1",
      "modules": ["module-a"],
      "files": [
        {
          "path": "src/main/java/com/example/Controller.java",
          "size_bytes": 5678
        }
      ]
    }
  ]
}
```

### 3.3 interfaces.json

```json
{
  "schema_version": "1.0",
  "interfaces": [
    {
      "interface_id": "intf-001",
      "protocol": "REST",
      "path": "/api/users",
      "method": "GET",
      "parameters": [
        {
          "name": "userId",
          "type": "string",
          "in": "path",
          "required": true
        }
      ],
      "response_schema": {},
      "code_location": {
        "repo": "/path/to/repo1",
        "file": "UserController.java",
        "line_range": [10, 25]
      }
    }
  ]
}
```

## 四、字段对齐检查

| 产物字段 | 对应 09 API 字段 | 说明 |
|----------|-----------------|------|
| interfaces.json.interface_id | API response.interface_id | 一致 |
| interfaces.json.protocol | API response.protocol | 一致 |
| interfaces.json.path | API response.path | 一致 |
| interfaces.json.parameters | API response.parameters | 一致 |
| execution.json.results | API response.results | 一致 |

## 五、索引与约束

| 产物 | 主键 | 索引 | 约束 |
|------|------|------|------|
| requirements.json | items[].id | - | id 全局唯一 |
| interfaces.json | interfaces[].interface_id | protocol | interface_id 全局唯一 |
| mapping.json | mappings[].requirement_id | status | requirement_id 唯一 |
| execution.json | results[].case_id | status | case_id 唯一 |
| defects.json | defects[].defect_id | case_id, status | defect_id 唯一 |
