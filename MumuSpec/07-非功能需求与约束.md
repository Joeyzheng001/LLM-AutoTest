## 一、性能需求

| # | 指标 | 量化要求 | 验证方式 |
|---|------|----------|----------|
| NFR-P01 | 单节点执行超时 | 单用例执行超时上限 30s | 执行引擎配置 |
| NFR-P02 | LLM 调用超时 | 单次 LLM 调用超时 60s，重试 1 次 | orchestrator 配置 |
| NFR-P03 | 报告生成时间 | 执行结束到报告产出 < 10s | 实测 |

## 二、可用性需求

| # | 指标 | 量化要求 | 验证方式 |
|---|------|----------|----------|
| NFR-A01 | 错误提示 | 所有错误场景给出明确提示，不静默失败 | 测试覆盖 |
| NFR-A02 | 断点续跑 | 节点产物已存在时可跳过该节点 | 实测 |
| NFR-A03 | 降级策略 | 不可用协议降级为"脚本生成 + Mock 演示" | 实测 |

## 三、可审计性需求

| # | 指标 | 量化要求 | 验证方式 |
|---|------|----------|----------|
| NFR-S01 | 节点执行日志 | 每个节点记录执行日志（含命令清单与产物变更时间戳） | 日志检查 |
| NFR-S02 | 缺陷生命周期 | 状态流转记录时间戳，形成可审计的缺陷生命周期 | 产物检查 |
| NFR-S03 | LLM 调用留痕 | 每次 LLM 调用记录输入摘要、输出、耗时、token 数 | 日志检查 |

## 四、约束

| # | 约束 | 说明 |
|---|------|------|
| C01 | LLM 唯一 | 仅允许调用 GLM-5.3，禁止引入其他模型 |
| C02 | 周期约束 | 一周内完成全部交付 |
| C03 | 无历史数据 | 无历史测试用例、无历史缺陷数据 |
| C04 | 无接口文档 | 以 LLM 代码逆向解析为唯一接口来源 |
| C05 | 分母固定 | 自动化率分母固定为 9 节点，降级节点按"人工介入"计入 |
| C06 | 报告数字不经 LLM | 测试报告中的数值只能由 execution.json 程序化汇总产生 |

## 五、度量口径声明

**项目口径 ≠ 生产口径**：
- "缺陷提交"节点在本项目中 = 生成本地缺陷记录文件，记为自动化节点
- 生产环境中该节点为人工提交至缺陷管理系统
- 本项目自动化率不得直接外推为生产预期
