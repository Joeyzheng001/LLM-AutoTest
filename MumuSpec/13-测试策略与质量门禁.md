## 一、测试分层

| 层级 | 说明 | 对应门禁 |
|------|------|----------|
| L1 Lint | 代码静态检查（ruff / mypy / checkstyle） | G-LINT |
| L2 Unit | 单元测试（pytest / JUnit） | G-UNIT |
| L3 Integration | 集成测试（服务间 API 调用） | G-INT |
| L4 E2E | 端到端测试（全流水线执行） | G-E2E |

## 二、质量门禁

| 门禁 | 触发时机 | 通过条件 |
|------|----------|----------|
| G-LINT | 每次提交 | 零 lint 错误，mypy strict 通过 |
| G-UNIT | 每次提交 | 单元测试 100% 通过 |
| G-INT | PR 合入前 | 集成测试通过（服务间 API 调用正常） |
| G-E2E | 验收前 | 端到端流水线跑通，自动化率实测 |
