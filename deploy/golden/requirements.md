# 用户中心与订单中心需求（LLM-AutoTest 验收 G2 样例——Markdown 版）

## 1. 用户查询（P1）

系统应支持按用户 ID 查询单个用户，返回该用户的完整信息（编号、姓名、邮箱、年龄）。
用户不存在时返回错误提示。

## 2. 用户列表过滤（P2）

系统应支持查询用户列表，可选按最小年龄过滤，仅返回年龄不低于给定值的用户。

## 3. 用户创建（P1）

系统应支持创建新用户，提交姓名、邮箱、年龄，创建成功后返回系统分配的用户编号。

## 4. 用户信息更新与删除（P2）

系统应支持按用户 ID 更新用户信息（姓名、邮箱、年龄）；支持按用户 ID 删除用户，
删除成功无返回内容。

## 5. 订单查询（P1）

订单中心应支持按订单 ID 查询单个订单；支持按用户 ID 过滤该用户的订单列表；
支持创建新订单。
